# L'Élixir & co — Luxury Fragrance Storefront

A responsive, front-end e-commerce website prototype for a luxury perfume boutique.

## Run locally
1. Extract the ZIP file.
2. Open the `le_lixir_co` folder in Visual Studio Code.
3. Open `index.html` in a browser. For a smoother developer experience, install the VS Code extension **Live Server**, right-click `index.html`, and choose **Open with Live Server**.

No build tools or package installation are required.

## Included
- Homepage with hero, best sellers, new arrivals, categories, fragrance families, reviews and newsletter
- Shop catalog with filters, sorting and search
- Product quick views, notes pyramid, size options, add-to-cart and wishlist
- Cart drawer, quantity editing, promo code demo (`ELIXIR10`) and demo checkout
- Wishlist and account demo pages
- About, contact, FAQ, shipping, returns, privacy, terms, tracking, discovery set, journal and brand pages
- Responsive mobile layout
- Browser localStorage for cart and wishlist

## Important demo limitations
This is a fully interactive **front-end prototype**, not a production commerce backend:
- No real payment processing, orders, user accounts, email sending, live inventory or shipment tracking
- Product names, brands, prices, reviews, policy text and imagery are illustrative
- Newsletter/contact forms show local demo confirmations only
- Before a real launch, connect a backend or commerce platform (e.g. Shopify/WooCommerce), configure payment and shipping, confirm product sourcing/authenticity, and replace demo policies with legally reviewed copy
- Images are loaded from Unsplash URLs and Google Fonts are loaded online

## GitHub
Create a new GitHub repository, then upload these files (or push the folder from VS Code). For a static demo, GitHub Pages can publish `index.html` directly:
1. In GitHub, create a repository.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
